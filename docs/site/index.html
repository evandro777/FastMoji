FastMoji

A popup emoji picker for Linux that is light and fast.

GitHub · Releases

Press a shortcut, search, pick

The emoji is pasted into the app you were using. Written in Rust with Slint, inspired by Emote, and focused on startup time and memory.

~23 MBidle memory (Emote: ~99 MB)
6–12 msshortcut to window mapped (Emote: 130 ms)
0.3 msper-keystroke search

Features

  • Instant search, 9 categories that follow scrolling, recent emojis first
  • Keyboard first: arrows, Enter to paste, Shift+Enter for several emojis, Esc to close
  • Skin tone, emoji size and automatic paste options
  • Global shortcut you set by pressing the keys (default Ctrl+Alt+.) on X11
  • Optional: do not stay in memory, and open it with your desktop's own shortcut
  • Follows the light/dark theme

Status: early pilot. Works on X11 (tested on Cinnamon). On Wayland it copies to the clipboard only; bind a key to fastmoji --toggle.

Install with Flatpak

This remote keeps FastMoji updated with flatpak update:

flatpak remote-add --user --if-not-exists fastmoji https://evandro777.github.io/FastMoji/fastmoji.flatpakrepo
flatpak install --user fastmoji io.github.evandro777.FastMoji

The runtime comes from Flathub. The remote is not GPG-signed, so it is as trustworthy as the source repository it is built from. You can also download a single .flatpak file from Releases; that one does not update by itself.
